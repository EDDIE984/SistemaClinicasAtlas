Manual de Usuario para Servicio de Imagen

Guia para gestionar citas de servicios de imagen, registrar pedidos medicos, atender citas asignadas y finalizar resultados con documentos PDF.

ModuloServicio de Imagen
Roles incluidosGestor Imagen · Usuario Imagen
VersionJunio 2026

1. Objetivo del manual

Este manual explica como operar el flujo de Servicio de Imagen dentro del sistema. Esta dirigido al personal que agenda, confirma, revisa y atiende citas de imagen.

Resultado esperado El usuario debe poder encontrar una cita, revisar la fotografia del pedido, gestionar la atencion y consultar o cargar resultados sin depender de soporte tecnico.

2. Alcance

Este documento incluye solamente operaciones relacionadas con Servicio de Imagen.

Incluye

  • Dashboard de Servicios.
  • Agenda de Servicios.
  • Citas de imagen y laboratorio cuando se gestionan desde el modulo de servicios.
  • Fotografia del pedido medico.
  • Confirmacion de cita.
  • Inicio y registro de atencion.
  • Finalizacion con PDF de resultado.
  • Carga de fotografia recibida por WhatsApp mediante integracion.

No incluye

  • Configuracion del sistema.
  • Creacion o administracion de usuarios.
  • Consulta externa.
  • Historia clinica de consulta externa.
  • Administracion general, reportes financieros o permisos.

3. Flujo general del Servicio de Imagen

  1. Se crea o existe una cita de servicio para un paciente.
  2. El pedido medico puede registrarse desde el dashboard o recibirse desde WhatsApp.
  3. El Gestor Imagen revisa la cita, valida datos y confirma si corresponde.
  4. El Usuario Imagen revisa sus citas asignadas en la agenda de su servicio.
  5. El Usuario Imagen inicia atencion, registra observaciones o URL de informe y guarda la atencion.
  6. El Gestor Imagen puede finalizar la cita subiendo el PDF de resultado.
  7. Una cita finalizada permite consultar el PDF o reemplazarlo si fue necesario.

4. Roles de Servicio de Imagen

Gestor Imagen

Supervisa las citas de servicios, confirma pedidos, consulta fotos, cancela o edita citas accionables y finaliza resultados con PDF.

  • Accede a Dashboard de Servicios.
  • Accede a Agenda de Servicios.
  • Puede usar filtros por sucursal, servicio y fechas.
  • Puede ver fotografia del pedido y resultado PDF.

Usuario Imagen

Atiende las citas confirmadas asignadas a su sucursal y servicio. Su vista esta orientada al trabajo diario de atencion.

  • Accede a su Agenda.
  • Visualiza sucursal y servicio asignado.
  • Filtra por estado.
  • Inicia, continua o guarda la atencion.

5. Uso del rol Gestor Imagen

5.1 Ingreso al Dashboard de Servicios

Al iniciar sesion como Gestor Imagen, el sistema muestra el Dashboard de Servicios. Esta pantalla concentra las citas de servicios de imagen y laboratorio.

Captura sugerida: Dashboard de Servicios completo.

5.2 Uso de filtros

Los filtros permiten ubicar citas por sucursal, servicio y rango de fechas. Presione Actualizar si desea recargar la pantalla.

FiltroUso
SucursalMuestra citas de una sucursal o todas las sucursales.
ServicioMuestra un servicio especifico, como Tomografia o Rayos X.
DesdeFecha inicial del rango de busqueda.
HastaFecha final del rango de busqueda.

Captura sugerida: bloque de filtros en dos columnas.

5.3 Lectura de la tabla de citas

La tabla muestra la informacion principal para operar cada cita:

  • Fecha y hora de la cita.
  • Servicio solicitado.
  • Paciente y cedula.
  • Medico solicitante y numero de registro, si existen.
  • Seguro medico.
  • Fotografia del pedido.
  • Estado de la cita.
  • Acciones disponibles.

Captura sugerida: tabla con una cita que tenga foto activa.

5.4 Ver fotografia del pedido

  1. Ubique la cita en la tabla.
  2. En la columna Foto pedido, presione Ver foto.
  3. El sistema abre un visor con la fotografia registrada.
  4. Use Descargar imagen si necesita guardar una copia local.
Importante Si la columna muestra Sin foto, no hay una imagen valida registrada para esa cita. Verifique que el pedido haya sido enviado correctamente.

Captura sugerida: dialogo de fotografia del pedido.

5.5 Confirmar cita desde el dashboard

Cuando una cita esta en estado Agendada, puede aparecer la accion Confirmar. Para confirmar, complete los datos requeridos.

  1. Presione Confirmar en la fila de la cita.
  2. Ingrese el medico solicitante.
  3. Ingrese el numero de registro medico.
  4. Indique si tiene seguro medico.
  5. Cargue la fotografia del pedido.
  6. Presione Confirmar cita.

Captura sugerida: formulario Confirmar cita.

5.6 Finalizar cita con PDF

El Gestor Imagen puede subir el PDF del resultado para marcar la cita como finalizada.

  1. Ubique una cita que aun no este finalizada.
  2. Presione Finalizar.
  3. Seleccione un archivo PDF del resultado.
  4. Presione Confirmar y Finalizar.
Restriccion El sistema acepta solamente archivos PDF de hasta 10 MB.

Captura sugerida: modal Finalizar cita con PDF.

5.7 Ver o reemplazar PDF de resultado

Cuando la cita esta en estado Finalizado, la tabla muestra acciones para consultar el PDF o reemplazarlo.

  • Ver PDF: abre el resultado en una nueva ventana.
  • Reemplazar: permite cargar un nuevo PDF, eliminando el anterior.

Captura sugerida: fila finalizada con botones Ver PDF y Reemplazar.

6. Uso del rol Usuario Imagen

6.1 Ingreso a Agenda

El Usuario Imagen ingresa directamente a la Agenda de su servicio asignado. La pantalla muestra las citas del servicio, con vista de semana o lista.

Captura sugerida: agenda del Usuario Imagen.

6.2 Filtros del Usuario Imagen

En modo Usuario Imagen, la sucursal y el servicio se muestran como datos asignados. El usuario puede cambiar el estado de filtro y alternar entre Semana y Lista.

ControlDescripcion
SucursalMuestra la sucursal asignada al usuario.
ServicioMuestra el servicio asignado al usuario.
EstadoPermite ver Confirmadas, En atencion, Atendidas, Agendadas, Canceladas o Todas.
SemanaMuestra las citas distribuidas por dia.
ListaMuestra las citas en tabla y permite usar rango de fechas.

6.3 Revisar detalle de cita

  1. Seleccione una cita desde la agenda semanal o la lista.
  2. Revise los datos de la cita y del cliente.
  3. Revise los datos de confirmacion medica.
  4. Presione Ver fotografia del pedido si necesita consultar la orden enviada.

Captura sugerida: dialogo Detalle de la cita.

6.4 Iniciar atencion

Si la cita esta en estado Confirmada, el usuario puede iniciar la atencion.

  1. Abra el detalle de la cita.
  2. Presione Inicio de atencion.
  3. El sistema cambia la cita a estado En atencion.
  4. Se abre la pantalla de atencion de servicio.

6.5 Guardar atencion

En la pantalla Atencion de servicio, el usuario puede registrar la URL del informe y observaciones de la atencion.

  1. Ingrese una URL valida si el informe se encuentra publicado externamente.
  2. Agregue observaciones si corresponde.
  3. Presione Guardar.
  4. La cita cambia a estado Atendida.

Captura sugerida: pantalla Atencion de servicio.

6.6 Cancelar cita con observacion

Si es necesario cancelar una cita desde la atencion del servicio, se debe registrar una observacion.

  1. Abra el detalle de la cita.
  2. Presione Cancelar cita.
  3. Escriba el motivo de cancelacion.
  4. Presione Confirmar cancelacion.

7. Carga de pedido desde WhatsApp

El paciente o personal autorizado puede enviar una fotografia del pedido medico por WhatsApp. La integracion recibe la imagen, la descifra y la envia al servicio de carga de imagen.

  1. El mensaje de WhatsApp contiene una imagen del pedido medico.
  2. La integracion descarga y descifra la imagen.
  3. La imagen se convierte a base64 valido.
  4. El servicio guarda la imagen en la cita correspondiente.
  5. El Dashboard de Servicios muestra la accion Ver foto.
No enviar archivos cifrados La URL cruda de WhatsApp puede devolver media cifrada. La integracion debe descifrar la imagen antes de enviarla al sistema.

Captura sugerida: conversacion de WhatsApp con la foto del pedido, ocultando datos sensibles.

8. Estados de la cita

EstadoSignificado operativoAcciones usuales
AgendadaLa cita fue creada, pero aun puede requerir datos o confirmacion.Confirmar, editar o cancelar.
ConfirmadaLa cita esta lista para atencion del servicio.Usuario Imagen puede iniciar atencion.
En atencionEl servicio ya inicio la atencion del paciente.Continuar atencion y guardar.
AtendidaLa atencion fue registrada como completada.Consulta de historial operativo.
FinalizadoEl resultado PDF fue cargado por Gestor Imagen.Ver PDF o reemplazar PDF.
CanceladaLa cita fue cancelada.No se debe atender.
No asistioEl paciente no asistio.No se debe atender.

9. Errores frecuentes y solucion

SituacionCausa probableQue hacer
No aparece la cita esperada Rango de fechas, sucursal o servicio incorrecto. Revise filtros y presione Actualizar.
La columna muestra Sin foto No hay imagen valida registrada. Solicite reenviar la fotografia o verifique la integracion de WhatsApp.
No se puede visualizar la foto Archivo corrupto o no corresponde a una imagen real. Vuelva a cargar la foto desde el archivo original.
No se puede finalizar con PDF Archivo no es PDF o supera 10 MB. Seleccione un PDF valido menor o igual a 10 MB.
No permite guardar atencion URL de informe invalida. Use una URL que inicie con http:// o https://, o deje el campo vacio si no aplica.
